# Ragnarok เกมข้อความ — บันทึกการออกแบบ

## ข้อตกลงที่ยืนยันแล้ว

- ร่วมกันออกแบบเกม Ragnarok แบบตัวหนังสือ เพื่อเล่นผ่านแชทภายหลัง
- ตอนนี้ยังไม่เริ่มเล่น ยังไม่สร้างตัวละครหรือเซฟ
- เก็บงานออกแบบและแหล่งอ้างอิงใน GitHub เพื่อพัฒนาต่อและกลับมาเล่นภายหลัง
- ใช้ [rAthena fork ของผู้เล่น](https://github.com/zeroice-ice/rathena) เป็นฐานอ้างอิง โดยต้นทางคือ [rathena/rathena](https://github.com/rathena/rathena)
- ใช้ระบบ **Renewal** เป็นฐาน
- **เริ่มเฉพาะช่วงแรกก่อน** ถ้าสนุกจึงค่อยขยาย ผู้เล่นยังไม่ต้องการกำหนดระบบใหญ่หรือปลายเกม
- ศึกษากลไกเดิมให้ละเอียดก่อนเสนอให้คิดกติกาขึ้นใหม่

## งานศึกษาที่มีแล้ว

อ่าน [รายงานศึกษา rAthena ภาษาไทย](research/RATHENA_STUDY.th.md) ซึ่งอ้างอิง source snapshot และบรรทัดต้นทาง พร้อม [รายการแหล่งข้อมูล](research/SOURCE_MANIFEST.json) และ [ตัวอย่างข้อมูลช่วงต้น](research/EARLY_REFERENCE.json)

พบเส้นทางเริ่มต้นเดิม ได้แก่ Human Novice → เรือ/เกาะเริ่มต้น → Izlude → Criatura Academy รวมทั้งกติกาการเติบโต การต่อสู้ ไอเทม เควสต์ และข้อยกเว้นของ Novice ข้อมูลเหล่านี้ใช้ศึกษาเป็นฐานได้โดยยังไม่ต้องกำหนดอาชีพปลายทาง

รายงานเป็นการตรวจ source แบบ static ยังไม่ได้รันเซิร์ฟเวอร์หรือรับรองทุก branch ของเกม

## วิธีพัฒนาต่อ

- ใช้กติกาและข้อมูลเดิมที่เกี่ยวข้องกับฉากช่วงแรกเป็นจุดตั้งต้น
- ตรวจข้อมูลร่วม ตัวโหลด ค่าเริ่มต้น การตั้งค่า สคริปต์ และโค้ดประกอบกัน
- ส่วนที่ปรับเพื่อเล่นผ่านแชทต้องแยกจากกติกาเดิม และระบุว่าเป็นข้อเสนอจนกว่าจะตกลง
- ยังไม่เลือกแทนผู้เล่นว่าจะใช้เซิร์ฟเวอร์จริงหรือตัวจำลองเฉพาะช่วงต้น
- เอกสารและข้อมูลใน research/ เป็นแหล่งอ้างอิง ไม่ใช่กติกาแชทฉบับสมบูรณ์หรือเซฟเกม

## เรื่องที่พักไว้จนกว่าจะจำเป็น

ยังไม่กำหนด Episode, เพดานเลเวล, อาชีพสูงสุด, เนื้อหาทั้งโลก หรือระบบปลายเกม และไม่ถือว่าต้องตัดสินใจเรื่องเหล่านี้ก่อนทดลองช่วงเริ่มต้น
