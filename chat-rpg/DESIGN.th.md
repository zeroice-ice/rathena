# Ragnarok เกมข้อความ — บันทึกการออกแบบ

## ข้อตกลงที่ยืนยันแล้ว

- ออกแบบเกม Ragnarok แบบตัวหนังสือเพื่อเล่นผ่านแชทภายหลัง
- ช่วงนี้เป็นการร่วมกันคิดและสร้างกติกา ยังไม่เริ่มเล่นและยังไม่สร้างเซฟตัวละคร
- บันทึกข้อตกลงและงานออกแบบลง GitHub เพื่อกลับมาพัฒนาหรือเล่นต่อได้
- ใช้ rAthena จาก https://github.com/zeroice-ice/rathena เป็นฐานอ้างอิง โดยต้นทางคือ https://github.com/rathena/rathena
- ผู้เล่นเลือกใช้ระบบ **Renewal** เป็นฐาน ไม่ใช้ Pre-Renewal เป็นฐานหลัก

## ขอบเขตของคำว่า Renewal

การเลือก Renewal ระบุฐานระบบเท่านั้น ยังไม่ได้กำหนด Episode, อาชีพสูงสุด, เลเวลสูงสุด หรือการเปิดใช้เนื้อหาทั้งหมดที่มีอยู่ใน rAthena

แหล่งเริ่มสำรวจข้อมูล: [db/re](../db/re) และข้อมูลร่วมใน [db](../db) ส่วนสูตรคำนวณและพฤติกรรมบางส่วนอยู่ในโค้ดและการตั้งค่า จึงไม่ถือว่า db/re เพียงอย่างเดียวเป็นกติกาครบชุด

## ข้อเสนอสำหรับการออกแบบ — ยังไม่ได้ยืนยัน

1. รักษาเอกลักษณ์ Base Level / Job Level, STR / AGI / VIT / INT / DEX / LUK, HP / SP, อาชีพ, ธาตุ, การ์ด และอุปกรณ์
2. แปลงการต่อสู้ตามเวลาจริงเป็นการผลัดเทิร์น โดยต้องออกแบบผลของ ASPD, เวลาร่าย, cooldown และระยะเวลา buff อย่างชัดเจน
3. ให้โปรแกรมคำนวณและสุ่มตามกติกาที่ตกลง ส่วน AI บรรยายโลกและรับการกระทำจากผู้เล่น
4. เก็บสถานะตัวละคร กระเป๋า เควสต์ และโลกในไฟล์ที่ตรวจสอบได้ เพื่อกลับมาเล่นต่อข้ามแชท
5. เริ่มออกแบบพื้นที่และวงจรการเล่นขนาดเล็ก ก่อนขยายเนื้อหา

## ประเด็นที่ต้องร่วมกันตัดสินใจ

- อาชีพและเพดานเลเวลที่เปิดใช้ในรุ่นแรก รวมถึง Episode อ้างอิง
- ความใกล้เคียงสูตร Renewal ต้นฉบับ เทียบกับความกระชับในการเล่นผ่านแชท
- หน่วยเวลาของเทิร์นและการแปลงระบบตามเวลาจริง
- การเดินทาง การฟาร์ม การตาย เศรษฐกิจ และอัตราดรอป
- โครงสร้างเซฟและวิธีกลับมาเล่นต่อ

## การจัดเก็บ

เอกสารออกแบบเกมแชทอยู่ใน chat-rpg/ แยกจากข้อมูลต้นฉบับของ rAthena แต่ละระบบที่จะนำมาใช้ต้องระบุแหล่งข้อมูลและส่วนที่ดัดแปลง ข้อเสนอจะเปลี่ยนเป็นข้อตกลงเมื่อผู้เล่นยืนยันแล้ว
